# Автосервис «Ключ» — Лендинг

## О проекте
Лендинг для автосервиса «Ключ» в Липецке. Современный тёмный дизайн на Astro + Tailwind CSS.

## Данные
- **Название:** Автосервис «Ключ»
- **Адрес:** Индустриальная ул., 4/1, Липецк
- **Рейтинг:** 4.8 (62 оценки)
- **Телефон:** +7 (4742) 39-99-95
- **Режим работы:** 9:00–19:00, без выходных

## Услуги
- Диагностика
- Ремонт подвески
- Ремонт ДВС
- Ремонт тормозов
- Замена масла
- Выхлопная система
- Шиномонтаж
- Автозапчасти
- Автомойка

## Стек
- Astro 5.x
- Tailwind CSS 3.x
- TypeScript
- GitHub Pages (деплой)

## Структура
- `src/pages/index.astro` — главная страница
- `src/layouts/Layout.astro` — layout
- `public/images/` — фото
- `dist/` — собранный сайт
- `docs/` — анализ и КП

## Запуск
```bash
npm install
npm run dev
```

## Деплой
Автодеплой через GitHub Actions при пуше в `main`.
